## 📌 About This Repository

As a Computer Science and Engineering undergraduate at the Bangladesh University of Engineering and Technology (BUET), I created this repository to serve as a centralized hub for my data science journey. 

This workspace transitions from fundamental Python programming to advanced data manipulation, data visualization, and the implementation of various Machine Learning algorithms. It acts as both a personal reference guide and a public portfolio of my analytical problem-solving skills.

## 📂 Repository Structure

The repository is highly organized to ensure smooth navigation through different learning phases:

* **[`/Basic Ideas`](./Basic%20Ideas)** 
  * Foundational Python concepts, syntax, data structures, and standard libraries.
* **[`/Pandas`](./Pandas)** *(and Data Manipulation)*
  * Exploratory Data Analysis (EDA), data cleaning, manipulation, and feature engineering using `pandas` and `numpy`.
* **[`/Machine Learning algo`](./Machine%20Learning%20algo)**
  * Step-by-step implementation of core ML algorithms (Regression, Classification, Clustering).
  * Model evaluation, hyperparameter tuning, and predictive analysis.
* **Datasets & Workspaces**
  * Practical implementations using sample datasets (e.g., `cows_and_goats.csv`) utilizing Jupyter Notebooks (`.ipynb`) for interactive and documented coding.
